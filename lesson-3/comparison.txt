# Порівняння Docker-образів для ML-моделі

## 1. Fat-image
- Розмір: 1.73 GB
- Основні шари:
  - Встановлення системних пакетів (build-essential, libjpeg-dev) та Python: ~600 MB
  - Встановлення Python-бібліотек (torch, torchvision, pillow): ~606 MB
  - Копіювання TorchScript моделі: 14.5 MB
  - Решта: базові шари python, конфігурація середовища
- Особливості:
  - Включає всі build-інструменти і кеш pip
  - Підходить для локальної розробки та тестування
  - Великий розмір, зайві пакети для production

## 2. Slim-image
- Розмір: 757 MB
- Основні шари:
  - Копіювання вже встановлених бібліотек з builder stage: 593 MB
  - Копіювання TorchScript моделі: 14.5 MB
  - Мінімальні системні пакети для runtime: 1–4 MB
- Особливості:
  - Multi-stage build (builder + runtime) зменшив розмір
  - Build-інструменти та кеш pip не потрапили у фінальний образ
  - Оптимальний для production, CI/CD і швидкого розгортання

## Висновки та рекомендації
- Fat-image підходить для швидкого локального тестування і розробки.
- Slim-image оптимізований для продакшну: менший розмір, менше зайвих шарів.
- Подальші оптимізації:
  - Використання distroless або alpine-базових образів для runtime
  - Видалення непотрібних Python-залежностей або використання torchscript-lite
  - Стиснення моделі та оптимізація її ваги
